# Prova P2 de Desenvolvimento Mobile

Aplicativo de Controle de Abastecimento em Flutter

- CRUD de veiculos e abastecimentos
- Cálculos de consumo com base no último abastecimento
- Cálculo de preço por litro
- Listagem de veículos e de respectivos abastecimentos
- Tema modo claro e escuro
- Autenticação
- Aplicativo funcional em Android

Ferramentas

- Flutter
- Firebase e Firestore
- Provider
- Flutter Chart
